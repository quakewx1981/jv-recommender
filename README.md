# JAV 智能推荐（javdb / javbus）

根据影片「评分 + 热度」综合评定，在 javdb / javbus 页面推荐 10 部影片的 Tampermonkey 油猴脚本。

## 功能
- **贝叶斯加权评分**（借鉴 [Javdb 增强脚本](https://sleazyfork.org/scripts/539525)）：
  `加权分 = (评分人数 × 平均分 + m × C) / (评分人数 + m)`
  - `m` = 基准人数（默认 200，虚拟评分人数；越大越保守，越依赖真实评分）
  - `C` = 基准分（默认 3.75，5 分制；同时是「隐藏低分」阈值）
  - 效果：5 人打 4.9 分会被拉回 3.78，5000 人打 4.29 分仍保持 4.27 —— 冷门高分不再刷榜
- **综合评分** = `0.6 × 加权分归一 + 0.4 × 热度归一`
  - 热度优先用真实数据（想看数 + 看过数），无该数据时退回列表位置
- **热力色**：综合徽章按加权分渐变（蓝=冷 → 绿 → 红=热），一眼看出冷热
- **数据源**：热播日/周/月榜、Top250、**全站候选(网页)**、关键字搜索、当前页面
- **全站候选(网页)**：逐页爬 javdb 全站最新流（`/?page=N`），默认最多 25 页（≈500 部全站快照，`CONFIG.allMaxPages` 可调）；先以网页评分角标粗排，取潜力 Top 80（`CONFIG.allEnrichN`）补真实详情（评分/评分人数/想看·看过），使评分口径与热播榜/搜索等 API 源一致；关闭 `enrichAll` 则退回纯网页角标。
- **搜索覆盖全站**：「关键字搜索」源由服务端按评分排序（5 分制）并翻多页（默认 3 页 × 40 = 约 120 候选），从全站匹配影片中产生结果；实测「搜索+补全评分」全程 < 3 秒
- **冷门过滤**：默认过滤「看过人数 < 200」的影片（`CONFIG.minWatched`），避免小众冷片刷入推荐；无该数据的条目保留不误杀
- **javdb 走 App JSON API**：热播榜/搜索直连 JavDB App API（逆向签名 `jdsignature`），并对候选影片并行拉详情补全评分（5 分制），比网页 DOM 解析更抗改版；Top250/当前页仍用网页列表。
- **主站/镜像自动切换**：App API 主站 `javdb.com` 不可达时自动回退镜像 `jdforrepam.com`（借鉴 javdb-cli 的 host 探测），避免单点被墙即全挂；首次成功后记住可用节点。
- **分类下拉 + 关键字输入 + 年代筛选**（年代按发行年过滤，配 Top250 可推「以前的高分热门」；分类按名称近似走搜索）
- **「推荐 10 部」** 取综合分 Top10；**「随机换一批」** 加权随机（偏高质量但换花样）
- 右上浮动面板，可拖拽 / 最小化，带调试日志

## 支持站点
- https://www.javdb.com
- https://www.javbus.com

## 安装
1. 安装浏览器扩展 Tampermonkey（或 Violentmonkey）。
2. 将 `jv-recommender-1.01.021.user.js` 内容粘贴进「添加新脚本」并保存；或直接把该 `.user.js` 拖入扩展安装。
3. 打开 javdb / javbus 任意页面，右上角出现面板即可使用。

## 说明 / 已知限制
- javdb 评分依赖封面角标 `.score`；javbus 列表页无评分，仅按热度（列表位置）推荐。
- 选择器默认值基于经验。若站点改版导致抓取为空，请用面板调试日志核对 `CONFIG.dom` 后手动调整。
- 版本号格式 `1.01.001`，文件名与脚本内 `@version` 同步。

## 更新 / 自动更新
- 脚本已配置 `@updateURL` 与 `@downloadURL`，指向本仓库 raw，支持 Tampermonkey / Violentmonkey 自动更新：
  - 检查更新：`jv-recommender.meta.js`（固定文件名，仅含版本信息，体积小、检查快）
  - 下载更新：`jv-recommender-1.01.021.user.js`（带版本号）
- 在扩展里对该脚本开启「检查更新 / 自动更新」即可，无需手动重装。

### 发版步骤（每次升版本都要做）
1. 修改脚本内 `@version` 为新版本（如 `1.01.002`）。
2. 将脚本文件重命名为对应版本号（`jv-recommender-1.01.002.user.js`）。
3. 同步修改脚本内 `@downloadURL` 末尾文件名、本 README「安装」步骤里的文件名。
4. 重新生成 `jv-recommender.meta.js`：把其中 `@version` 与 `@downloadURL` 文件名一并更新到新版本。
5. 提交并推送：
   ```bash
   git add -A && git commit -m "release: v1.01.002" && git push
   ```
